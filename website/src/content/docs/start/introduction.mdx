pro-sejongpeia는 **세종대학교 통합 라이브러리**입니다. 학번과 비밀번호로 재학생인지 확인하는 **포털 로그인**과, 로그인 없이 학교가 공개로 내려주는 **학교 데이터**(학과 코드, 개설강좌, 학사일정, 기숙사 식단, 학식 등)를 Java, Python, Node.js 어느 쪽에서든 같은 기능, 같은 결과 필드, 같은 에러 코드로 씁니다.

포털 로그인, SSO 리다이렉트, 세션 쿠키, 오래된 TLS 방식, HTML·JSON 파싱은 라이브러리가 처리합니다.

<Aside type="note" title="한눈에">
- **학생 인증**은 학번과 비밀번호가 필요하고, **학교 데이터**는 필요 없습니다.
- Java, Python, Node.js가 같은 기능, 같은 결과 필드, 같은 에러 코드를 씁니다.
- 학교 웹 화면이 쓰는 비공식 주소를 따라가므로, 학교가 바꾸면 멈출 수 있습니다.
</Aside>

## 알아 둘 점

- **세종대학교의 공식 제품이 아닙니다.** 세종대 학생이 만든 개인 오픈소스이며 학교와 제휴 관계가 없습니다.
- 학교가 문서로 공개한 API가 아니라 **학교 웹 화면이 쓰는 비공식 주소**를 따라갑니다. 학교가 바꾸면 동작이 멈출 수 있고, 매일 점검해서 깨지면 이슈로 고칩니다. 수정 시점에 대한 약속은 없습니다.
- **하위 호환을 보장하지 않습니다.** 같은 `1.x` 안에서도 깨지는 변경이 생길 수 있으니 버전을 정확히 고정하세요. [API 안정성](../../api-stability/)
- 학교 값은 **학교가 준 문자열 그대로**입니다. 코드표나 이름 매핑을 라이브러리가 들고 있지 않습니다.

## 요구 사항

| Java / Spring Boot | Python | Node.js |
|---|---|---|
| Java 17 이상, Spring Boot 3.x. 일반 Java도 가능 | Python 3.9 이상, 표준 라이브러리 외 의존성 없음 | Node 18 이상, 의존성 없음, TypeScript 타입 포함, ESM·CommonJS. 서버 전용 |

Java의 HTTP는 OkHttp, HTML 파싱은 jsoup을 씁니다.
