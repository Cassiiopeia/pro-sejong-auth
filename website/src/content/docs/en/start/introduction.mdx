pro-sejongpeia is an **integrated library for Sejong University**. It offers the **portal login** that verifies a student with a student ID and password, and the **school data** the university serves publicly without login (department codes, course listings, the academic calendar, dormitory menus, cafeterias and more). Java, Python and Node.js get the same features, the same result fields and the same error codes.

The portal login, SSO redirects, session cookies, the old TLS setup and HTML and JSON parsing are handled by the library.

<Aside type="note" title="At a glance">
- **Student verification** needs a student ID and password; **school data** does not.
- Java, Python and Node.js share the same features, result fields and error codes.
- It follows the unofficial addresses the school's web pages use, so it can stop working when the school changes them.
</Aside>

## How it works at a glance

One call goes through the library to the school servers, and the response comes back in the same shape.

## Who it is for

- **Sejong student verification** for clubs, student councils and campus communities
- Checking participation in campus events that depend on department or year
- Department and lecture search pages, academic calendar widgets
- Bots that post the dormitory menu and cafeteria menus

## Data sources

| Source | Domain | What it provides | Login |
|---|---|---|---|
| DHC (Daeyang Humanity College) | classic.sejong.ac.kr | Student info + classic-reading certification | required |
| SIS (student information system) | sjpt.sejong.ac.kr | Student info + email, phone, English name, school codes | required |
| SIS public lookups | sjpt.sejong.ac.kr | Organization categories, terms, departments, course listings | not needed |
| University website | www.sejong.ac.kr | Academic calendar, cafeterias, campus places, curriculum | not needed |
| Graduate school sites | `<site>.sejong.ac.kr` | Graduate academic calendar | not needed |
| Dormitory | happydorm.sejong.ac.kr | Dormitory menu, notices | not needed |
| Do-Dream | do.sejong.ac.kr | Extracurricular program schedule | not needed |

## Good to know

- **This is not an official Sejong University product.** It is a personal open-source project by a Sejong student and is not affiliated with the university.
- It follows **unofficial addresses used by the university's own web screens**, not a documented API. If the university changes them it can stop working; a daily check opens an issue when something breaks. There is no promise about how fast it gets fixed.
- **Backward compatibility is not guaranteed.** Breaking changes can happen even within `1.x`, so pin the exact version. [API stability](../../api-stability/)
- School values are **the strings the school sent, as they are**. The library carries no code tables or name mappings.

## Requirements

| Java / Spring Boot | Python | Node.js |
|---|---|---|
| Java 17+, Spring Boot 3.x. Plain Java works too | Python 3.9+, no dependencies beyond the standard library | Node 18+, no dependencies, TypeScript types included, ESM and CommonJS. Server only |

Java uses OkHttp for HTTP and jsoup for HTML parsing.
