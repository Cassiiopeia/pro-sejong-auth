Get the place list used by the school's campus map, without login. It has names, latitude and longitude and guide information for buildings and facilities, so you can use it directly in a map app or a campus guide service. Common rules are on [Common rules](../overview/).

## Request parameters

Python uses `snake_case` (`campus_places`); Node.js and Java use `camelCase` (`campusPlaces`). Java has two forms, `campusPlaces()` and `campusPlaces(String placeType)`; Node.js is `campusPlaces(placeType = '')`.

| Parameter | Type | Required | Default | Meaning |
|---|---|---|---|---|
| `place_type` | string | optional | `""` | The school's place type value. It is not a fixed list: pass a `place_type` value from the results to filter, or leave it empty for no type limit |

- Returns a list of `CampusPlace`.

**School request**

- `GET https://www.sejong.ac.kr/kor/intro/campus-map.do?mode=getPlaceUserList&placeType=<type>`, response array `items`.

## Response data structure

Example JSON. Field names are Python `snake_case`; Node.js and Java use `camelCase`. School data changes, so the values are examples.

```json
[
  {
    "id": "3",
    "name": "산들푸드",
    "name_en": "",
    "place_type": "WELFARE",
    "category": "식당",
    "latitude": 37.5495931628,
    "longitude": 127.0751638599,
    "info": "학생회관 B1층",
    "phone": "02-000-0000",
    "description": "",
    "extra": { "orderNo": "1", "useYn": "Y" }
  }
]
```

Missing values are empty strings; latitude and longitude are numbers (`0.0` when missing or unreadable).

| Field | School key | Meaning |
|---|---|---|
| `id` | `id` | Place number. A different system from the cafeteria numbers ([Cafeteria](../cafeteria/)) |
| `name`, `name_en` | `placeName`, `placeNameEn` | Korean and English name |
| `place_type` | `placeType` | Place type (for example `BUILDING`, `WELFARE`) |
| `category` | `welfareCategory` | Facility category |
| `latitude`, `longitude` | `latitude`, `longitude` | Latitude, longitude (floating point) |
| `info` | `placeInfo` | Guide information |
| `phone` | `telNum` | Phone number |
| `description` | `description` | Description |
| `extra` | other fields | Original school fields |

- Cached for one day (86400 seconds by default) per type value, with one school request per call.
- School-side failures (connection, timeout, bad response, missing `items`) return the last cached value or an empty list. With no cache, an empty list is returned without a request for 60 seconds (default).
- This method never raises.
- An empty list cannot tell "no places" from "a problem on the school side".

## Known limits

- The place `id` is a different system from the cafeteria numbers in the menu answers, and nothing links the two.
- A missing coordinate is `0.0`, so check before you plot a point.
- `phone` and `info` are the values the school entered. Review them before you pass them on to outside users.
- Contract source: [spec/PUBLIC_DATA.md](https://github.com/Cassiiopeia/pro-sejongpeia/blob/main/spec/PUBLIC_DATA.md)

List<CampusPlace> places = publicData.campusPlaces();
