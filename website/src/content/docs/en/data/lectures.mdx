Search a term's course listings by department code, course name and instructor name. All three are optional, and **with all of them empty you get the whole term** in one call. The library handles the request the school only accepts with every filter key present. Find department and term codes on [Department and term codes](../codes/). Common rules are on [Common rules](../overview/).

## Methods

| Language | Signature |
|---|---|
| Java | `lectures(String categoryCode, String year, String semesterCode, String departmentCode, String courseName, String instructorName)` |
| Python | `lectures(category_code, year, semester_code, department_code="", course_name="", instructor_name="")` |
| Node.js | `lectures({ categoryCode, year, semesterCode, departmentCode?, courseName?, instructorName? })` |

- `category_code`: organization category (undergraduate `20`, general graduate school `30`, ...). `year`: year as a string. `semester_code`: term code (`10`, `11`, `20`, `21`).
- In Java, pass an empty string (`""`) for the optional arguments you do not use.
- Returns a list of `Lecture`.

## Request notes

- `POST https://sjpt.sejong.ac.kr/sch/sch/ext/SueOpenTimeQ/doList.do`, body `{"dm_search": {...}}`, response dataset `dl_main`. No login.
- `dm_search` carries `ORGN_CLSF_CD`, `YEAR`, `SMT_CD`, `YEAR_SMT` (`<year>/<semester code>`), `DEPT_CD`, `CURI_NM`, `EMP_NM` and `LANG_CHK="KOR"`.
- **Every other filter key must be present, with an empty value.** If any of `SMT_NM`, `CURI_TYPE_CD`, `SLT_DOMAIN_CD`, `CURI_NO`, `CLASS`, `SLT_DEPT_CD`, `PLAN_REG_YN` or `CORS_SCHE_GRP_CD` is missing, the school answers `_SUBMIT_ERROR_` (checked on 2026-10-30 by leaving out one key at a time). The library always sends the full key set.
- **Values are trimmed before sending.** The school treats a single space as a search text: a space in the course name returned 179 of the 2,786 rows (2026-10-30).
- The school's own screen demands one of department, course name or instructor, but the server does not.

### With all conditions empty

Measured on 2026-10-30, term 2026/2, one call each.

| Organization category | Rows | Size | Time |
|---|---|---|---|
| Undergraduate `20` | 2,786 | 2.4 MB | 0.8 s |
| Graduate `30` | 1,132 | 0.9 MB | (not recorded) |

The undergraduate answer had 102 departments and no repeated course-section-department row. If you do not need everything, query **one department at a time**. A whole undergraduate term is a few MB per cache entry and stays in memory for `cache_ttl_seconds`.

## Result fields

Field names are Python `snake_case`; Node.js and Java use `camelCase`. All are strings, empty when missing. The model also has `extra` (the 33 fields the school gives per course, minus the ones used below).

| Field | School key | Meaning |
|---|---|---|
| `course_number` | `CURI_NO` | Course number |
| `section` | `CLASS` | Section |
| `name` | `CURI_NM` | Course name |
| `course_type_code`, `course_type_name` | `CURI_TYPE_CD`, `CURI_TYPE_CD_NM` | Course type code and name |
| `domain_code`, `domain_name` | `SLT_DOMAIN_CD`, `SLT_DOMAIN_CD_NM` | Selective domain code and name |
| `credits` | `CDT` | Credits (for example `3.0`) |
| `hours` | `TM_NUM` | Hours, as the school writes them (for example `3.0 / 3 / 0`) |
| `total_hours` | `TOT_TM_NUM` | Total hours |
| `schedule` | `LESN_TIME` | Class time (for example `화13:00-15:00`) |
| `room` | `LESN_ROOM` | Classroom |
| `instructor` | `LESN_EMP` | Instructor name |
| `grade_level` | `STUDENT_YEAR` | Year level |
| `language_code`, `language_name` | `CURI_LANG_CD`, `CURI_LANG_NM` | Teaching language |
| `department_code`, `department_name` | `DEPT_CD`, `SCH_DEPT_ALIAS` | Offering department code and name |
| `managing_department` | `MANAGE_DEPT_NM` | Managing department |
| `remark` | `REMARK` | Remark |
| `year`, `semester_code` | `YEAR`, `SMT_CD` | Year and term code |

<Aside type="caution" title="Instructor names are included">
`instructor` is the instructor name as the school publishes it in the timetable. If your service republishes the library's results, decide which fields to expose. The example in [Department and lecture search](../../guides/department-lecture-search/) also picks only the fields it needs.
</Aside>

With a lecture's `course_number` and `department_code` you can look up the suggested year, term and course overview from that department's curriculum ([Curriculum](../curriculum/)).

## Cache and failure behavior

- Cached for one day (86400 seconds by default) per combination of category, year, term, department code, course name and instructor name. One request per call.
- School failures (connection, timeout, bad response, `_SUBMIT_ERROR_`) return the last cached value or an empty list. With no cache, the same call returns an empty list without a request for `failure_cache_seconds` (default 60).
- `lectures` never raises because of its filters.
- An empty list can mean "no course matches" or "a problem on the school side". On 2026-10-30 the course name `자료구조` returned 0 rows, `알고리즘` 18 and `프로그래밍` 73 (partial matching).

## Known limits and what was not verified

- Unofficial endpoint. Behavior such as the filter-key requirement changes if the school changes it.
- The language filter is fixed to `LANG_CHK="KOR"`. Other values were not tried.
- Only the whole-term answers for undergraduate and graduate (`30`) were measured. The size for other organization categories was not measured.
- The instructor syllabus is not provided. Its report form carries the instructor's name and contact lines, so it was left out of the default scope ([survey notes](https://github.com/Cassiiopeia/pro-sejongpeia/blob/main/spec/REFERENCE_DATA_SURVEY.md)). The course overview is available as `overview` in [Curriculum](../curriculum/).
