학번과 비밀번호로 재학생 여부, 학과, 학년, 고전독서 인증, 연락처를 가져오고, 로그인 없이도 학과 코드, 개설강좌, 학사일정 같은 공개 데이터를 받습니다. SSO, 쿠키, HTML 파싱은 라이브러리가 처리합니다.

지금 바로 체험하기 설치 방법 보기

result.getMajor();   // "컴퓨터공학과"

무엇을 해 주나요

세종대 학생 인증이 필요한 서비스(동아리, 학생 커뮤니티, 학내 이벤트)를 위한 라이브러리입니다.

포털 SSO 자동 처리

세종 포털 로그인, SSO 리다이렉트, 세션 쿠키를 알아서 처리하고 비밀번호가 틀리면 바로 알려 줍니다.

학생 정보 + 고전독서

이름, 학과, 학년, 재학 상태와 대양휴머니티칼리지 고전독서 인증 현황을 구조화된 객체로 돌려줍니다.

설정 없이 바로

Spring Boot Auto Configuration으로 의존성만 추가하면 SuhSejongAuthEngine을 주입받아 씁니다.

직접 구현하면 어려운 것들

포털 로그인은 눈에 보이는 것보다 훨씬 까다롭습니다. 아래를 모두 라이브러리가 대신 처리합니다.

레거시 TLS 암호 처리

포털이 허용하는 유일한 암호(TLS_RSA_WITH_AES_256_CBC_SHA)를 최신 JDK, Python, Node 기본 설정이 막습니다. 언어마다 다른 방식으로 풀어 두었고, Spring Boot는 시작할 때 자동으로 적용합니다.

방화벽과 User-Agent

기본 라이브러리 User-Agent는 방화벽이 막고, 없으면 일부 사이트가 404를 돌려줍니다. 식별 가능한 User-Agent를 자동으로 보냅니다.

SSO 쿠키와 리다이렉트

세종대 도메인 여러 곳에 걸친 SSO 쿠키와 리다이렉트를 처리해, 로그인 한 번으로 DHC와 SIS를 모두 조회합니다.

로그인 판정과 계정 보호

200 응답 안의 스크립트 값으로 비밀번호 오류, 계정 잠금, 이용 불가를 즉시 구분합니다. 틀린 비밀번호는 재시도하지 않아 계정 잠금을 막습니다.

HTML 표와 JSON 파싱

DHC의 HTML 표와 SIS의 JSON API 응답을 정리된 결과 객체로 돌려줍니다.

세 언어 동일 동작

Java, Python, Node가 같은 결과를 내도록 공통 계약과 교차 검증으로 맞추고, 매일 실제 포털에 로그인해 점검합니다.

로그인 없이 쓰는 학교 데이터

학번과 비밀번호 없이 학교가 공개로 내려주는 정보를 세 언어에서 같은 메서드, 같은 결과로 받습니다. 한 곳이 실패해도 나머지는 그대로 동작하고, 결과는 메모리에 캐시합니다.

개설강좌와 학과 코드

학과, 과목명, 교수명으로 개설강좌를 찾고(모두 비우면 그 학기 전체), 단과대·학과·학기 코드는 학교 값 그대로 받습니다. 학교가 모든 필터 키를 요구하는 까다로운 요청은 라이브러리가 맞춥니다.

학사일정

기간을 주면 학부·대학원 학사일정을 날짜와 제목으로 돌려줍니다.

기숙사 식단과 공지

일주일 식단(조식·중식·석식)과 공지 목록을 받습니다. 작성자 필드는 결과에서 제외합니다.

학식 식당과 메뉴

식당 목록(번호·이름·건물·위치)과 식당별 메뉴, 가격을 받습니다. 날짜가 없는 고정 메뉴도 함께 돌려줍니다.

캠퍼스 장소

건물과 편의시설의 이름, 위치(위도·경도), 안내 정보를 받습니다.

비교과 프로그램 일정

기간별 비교과 프로그램을 분류와 함께 받습니다. 응답이 느린 학교 서버에 맞춰 캐시하고 실패를 격리합니다.

학사 업무 기간 (로그인)

수강신청, 성적 조회처럼 학사 업무별 기간을 받습니다. 학사정보시스템이 요구하는 실행 값 조합과 호출 순서는 라이브러리가 맞추고, 세션 값은 결과와 로그에 남기지 않습니다.

원문과 확장 필드 옵션

통합 인증에서 학교 원문 응답을 옵션으로 받고, 학교가 주는 나머지 사용자 필드는 extra로 받습니다. 세션·계정 상태·연락처 같은 민감한 필드는 항상 제외합니다.

학과 교육과정과 교과목 개요

학과 코드와 과목 번호로 권장 학년·학기, 이수 구분, 학점, 교과목 개요를 받습니다. 학교가 JSON 요청에 Accept 헤더를 요구하는 부분은 라이브러리가 맞춥니다.

3주입받아 호출

AuthController.java 
@RestController
@RequiredArgsConstructor
public class AuthController {

    private final SuhSejongAuthEngine sejongAuthEngine;

    @PostMapping("/auth/sejong")
    public SejongAuthResult authenticate(@RequestParam String studentId,
                                         @RequestParam String password) {
        return sejongAuthEngine.authenticate(studentId, password);
    }
}

사용법

필요한 정보에 맞는 메서드를 고르세요. 통합 인증은 연락처 조회가 실패해도 학생 정보는 돌려줍니다.

메서드용도반환
authenticate(id, pw)통합: 학생 정보 + 고전독서 + 연락처SejongAuthResult
authenticateWithDHC(id, pw)학생 정보 + 고전독서 (보장)SejongDhcAuthResult
authenticateWithSIS(id, pw)학생 정보 + 연락처 (보장)SejongSisAuthResult
authenticateWithDHCRaw(id, pw)DHC + 원본 HTML (디버깅)SejongDhcAuthResult
authenticateWithSISRaw(id, pw)SIS + 원본 JSON (디버깅)SejongSisAuthResult
고전독서 인증 확인 
SejongDhcAuthResult result = sejongAuthEngine.authenticateWithDHC(studentId, password);

for (ClassicCertification certification : result.getClassicReading().getCertifications()) {
    System.out.println(certification.getArea() + " "
        + certification.getCertifiedCount() + "/" + certification.getRequiredCount());
}
실패 처리 
try {
    sejongAuthEngine.authenticate(studentId, password);
} catch (SejongAuthException exception) {
    switch (exception.getErrorCode()) {
        case AUTHENTICATION_FAILED -> // 학번·비밀번호 불일치
        case CONNECTION_FAILED, CONNECTION_TIMEOUT -> // 포털 장애
        default -> // 파싱·세션 오류
    }
}

FAQ

세종대 로그인 API가 있나요?

네. pro-sejongpeia는 세종대학교 포털 로그인(SSO)을 대신 처리하고 로그인 없이 쓰는 학교 공개 데이터도 제공하는 Java·Python·Node.js 통합 라이브러리입니다. 학번과 비밀번호로 재학생 여부, 학과, 학년, 고전독서 인증, 연락처를 조회합니다.

비밀번호를 저장하나요?

라이브러리는 비밀번호를 저장하지 않고 포털 로그인 요청에만 씁니다. 이 페이지의 데모 서버도 결과만 돌려주고 입력값을 저장하지 않습니다. 실제 서비스에서는 비밀번호를 로그·DB에 남기지 않도록 주의하세요.

세종대학교 공식 라이브러리인가요?

아닙니다. 세종대 학생이 만든 개인 오픈소스이며 학교와 무관합니다. 포털 구조가 바뀌면 동작이 멈출 수 있고, 그때는 이슈로 알려 주세요.

요구 사항은?

Java 17 이상, Spring Boot 3.x. HTTP는 OkHttp, HTML 파싱은 jsoup을 씁니다.
